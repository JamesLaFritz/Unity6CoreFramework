CoreFramework API Reference

Welcome to the API reference for the CoreFramework — a modular Unity 6 framework providing:

  • Extensions
  • Mathematics utilities (ulong2, ulong4)
  • Patterns (Factory/IGameAssetFactory, SharedData, Visitor)
  • Random (noise-based RNGs: SquirrelNoise 32/64/128)
  • Settings (CoreFrameworkSettings, VersionControl)
  • Editor (Preferences & Project Settings providers, tools, build processing)
  • Bootstrapper (startup flow)
