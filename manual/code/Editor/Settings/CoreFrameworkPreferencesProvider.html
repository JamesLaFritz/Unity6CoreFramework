CoreFrameworkPreferencesProvider

Source: ./Editor/Settings/CoreFrameworkPreferencesProvider.cs

Overview

Implements the Unity Preferences integration for CoreFramework.
This class registers the CoreFrameworkPreferences page under:

Edit → Preferences → Core Framework → Settings

It does not hold any settings itself. Instead, it exposes the UI and binds to the data stored in CoreFrameworkPreferences.

Responsibilities

  • Adds a “Core Framework” entry in Unity’s Preferences window.
  • Draws the fields defined in CoreFrameworkPreferences (Show Debug, Info Size, Warning Size, Error Size).
  • Saves and loads those values using EditorPrefs.

This allows you to adjust the values per-developer without modifying project assets.

Usage

You generally do not use CoreFrameworkPreferencesProvider directly.
It runs automatically when Unity loads the editor.
You interact with the stored values through:

  • CoreFrameworkPreferences (editor side)
  • or your own scripts reading CoreFrameworkSettings (runtime mirror).
