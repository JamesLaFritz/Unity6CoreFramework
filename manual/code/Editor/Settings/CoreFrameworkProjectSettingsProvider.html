CoreFrameworkProjectSettingsProvider

Source: ./Editor/Settings/CoreFrameworkProjectSettingsProvider.cs

Overview

Registers the Project Settings UI for CoreFramework at:

Edit → Project Settings → Core Framework → Settings

The provider renders two dropdowns—Boot Scene and Start Scene—backed by CoreFrameworkProjectSettings.instance.
It also exposes a convenience menu item (Core Framework → Project Settings) to jump directly to the page.

Responsibilities

  • Path & scope: Project/Core Framework/Settings (project-scoped SettingsScope.Project).
  • Scene list: Reads enabled scenes from EditorBuildSettings.scenes; inserts a "None" option.
  • UI (IMGUI): Uses EditorGUILayout.Popup to select:
    • Boot Scene → CoreFrameworkProjectSettings.instance.BootScene
    • Start Scene → CoreFrameworkProjectSettings.instance.StartScene
  • Search keywords: "Boot Scene", "Start Scene" to improve settings search.
  • Menu item: Core Framework/Project Settings opens this page via SettingsService.OpenProjectSettings.

Note: There’s a commented-out UIElements version (OnActivate) in the file. The active implementation draws via IMGUI in OnGUI.

How it works (flow)

  1. Collect enabled scene paths → build a list, insert "None".
  2. Fetch CoreFrameworkProjectSettings.instance.
  3. Compute selected indices (fall back to "None" when not found).
  4. Draw the two popups; assign chosen values back to the settings instance.
// Excerpt (structure only)
public override void OnGUI(string searchContext)
{
    var scenesList = (from s in EditorBuildSettings.scenes where s.enabled select s.path).ToList();
    if (scenesList.Count > 0) scenesList.Insert(0, "None"); else scenesList.Add("None");

    var settings = CoreFrameworkProjectSettings.instance;

    var bootIndex  = scenesList.Contains(settings.BootScene)  ? scenesList.IndexOf(settings.BootScene)  : 0;
    var startIndex = scenesList.Contains(settings.StartScene) ? scenesList.IndexOf(settings.StartScene) : 0;

    settings.BootScene  = scenesList[EditorGUILayout.Popup("Boot Scene",  bootIndex,  scenesList.ToArray())];
    settings.StartScene = scenesList[EditorGUILayout.Popup("Start Scene", startIndex, scenesList.ToArray())];
}

Open it from a menu (and code)

  • Menu: Core Framework/Project Settings
  • Programmatically:
UnityEditor.SettingsService.OpenProjectSettings("Project/Core Framework/Settings");

Notes & tips

  • Ensure chosen scenes are added to File → Build Settings… so they can be loaded by name.
  • These values are team-shared (serialized), and later mirrored into CoreFrameworkSettings by CoreFrameworkSettingInitialization for runtime use (e.g., Bootstrapper scene loading).
