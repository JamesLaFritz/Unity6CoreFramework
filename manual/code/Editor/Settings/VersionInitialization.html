VersionInitialization

Source: ./Editor/Settings/VersionInitialization.cs

Overview

Ensures that version-related settings are synchronized between VersionProjectSettings, VersionControl, and Unity’s PlayerSettings.bundleVersion when the editor starts.

This keeps the project’s current and minimum file versions consistent and automatically updates the Unity bundle version if necessary.

How it works

VersionInitialization is marked with [InitializeOnLoad], so its static constructor runs automatically when the Unity Editor loads.

[InitializeOnLoad]
public class VersionInitialization
{
    static VersionInitialization()
    {
        // Retrieve the VersionProjectSettings instance
        var settings = VersionProjectSettings.instance;

        // Set the current and minimum save file versions from VersionProjectSettings
        VersionControl.CurrentFileVersion = settings.CurrentFileVersion;
        VersionControl.MinFileVersion     = settings.MinFileVersion;

        // Sync Unity PlayerSettings.bundleVersion
        if (Version.TryParse(PlayerSettings.bundleVersion, out var result) &&
            VersionControl.CurrentFileVersion < result)
        {
            // If bundleVersion is newer, update CurrentFileVersion
            settings.CurrentFileVersion = result;
        }
        else
        {
            // Otherwise, set the bundleVersion to CurrentFileVersion
            PlayerSettings.bundleVersion = settings.CurrentFileVersion.ToString();
        }
    }
}

Flow diagram

  1. Editor starts

  2. Static constructor runs.

  3. Reads VersionProjectSettings.instance (current & minimum file versions).

  4. Assigns values to VersionControl.CurrentFileVersion and VersionControl.MinFileVersion.

  5. Compares PlayerSettings.bundleVersion to CurrentFileVersion:

    • If Unity’s bundle version is newer → update CurrentFileVersion.
    • Otherwise → set Unity’s bundle version to match CurrentFileVersion.

Why it matters

  • Keeps your save file versions in step with project settings.
  • Ensures PlayerSettings.bundleVersion matches your CoreFramework versioning scheme, preventing mismatches between builds and save data.

Usage Notes

  • This runs only in the Unity Editor due to [InitializeOnLoad].
  • Make sure VersionProjectSettings is configured with the correct CurrentFileVersion and MinFileVersion.
