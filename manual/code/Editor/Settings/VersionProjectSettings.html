VersionProjectSettings

Source: ./Editor/Settings/VersionProjectSettings.cs

Overview

Holds the project-wide version settings (serialized and committed to VCS) used by CoreFramework to control save/version compatibility and to sync Unity’s PlayerSettings.bundleVersion.

Curently there is no save system in CoreFramework. This will be added at a later stage.

The asset is stored at:

ProjectSettings/VersionProjectSettings.asset

This class is a ScriptableSingleton<VersionProjectSettings>; access via VersionProjectSettings.instance.

Fields

Current Version

Represents the latest file format/version of your project.

  • Major — incompatible API/format changes
  • Minor — backward-compatible feature additions
  • Build — backward-compatible bug fixes
  • Revision — pre-release/internals
public Version CurrentFileVersion
{
    get => new(_major, _minor, _build, _revision);
    set
    {
        PlayerSettings.bundleVersion = value.ToString();
        VersionControl.CurrentFileVersion = value;
        _major = value.Major;
        _minor = value.Minor;
        _build = value.Build;
        _revision = value.Revision;
        Save(true);
    }
}

Setting CurrentFileVersion:

  • Updates UnityEditor.PlayerSettings.bundleVersion
  • Updates VersionControl.CurrentFileVersion
  • Saves the singleton asset

Min Version

The earliest save/file version that remains supported.

public Version MinFileVersion
{
    get => new(_minMajor, _minMinor, _minBuild, _minRevision);
    set
    {
        VersionControl.MinFileVersion = value;
        _minMajor = value.Major;
        _minMinor = value.Minor;
        _minBuild = value.Build;
        _minRevision = value.Revision;
        Save(true);
    }
}

Where to edit it (Unity)

Edit → Project Settings → Core Framework → Version Settings

How it fits together

  • On editor load, VersionInitialization copies these values to:

    • VersionControl.CurrentFileVersion
    • VersionControl.MinFileVersion
    • and syncs PlayerSettings.bundleVersion accordingly

  • Build menus in BuildProcessing bump version parts and assign back to CurrentFileVersion.

Usage snippet

// Bump build and persist everywhere (asset + PlayerSettings + VersionControl)
var v = VersionProjectSettings.instance.CurrentFileVersion;
VersionProjectSettings.instance.CurrentFileVersion = new Version(v.Major, v.Minor, v.Build + 1, 0);
