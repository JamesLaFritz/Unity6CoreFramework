NoiseEditorHelper

Source: ./Editor/Tools/NoiseEditorHelper.cs

Overview

NoiseEditorHelper is a static utility class used by CoreFramework editor windows such as CellularHeatmapWindow and SquirrelNoiseHeatMapWindow.
It centralizes the repetitive editor-UI code for creating textures, uploading noise buffers, drawing scaled previews, and saving PNGs.

This keeps each heatmap window small and focused on computing the values rather than worrying about Unity editor plumbing.

Responsibilities

Method Purpose
EnsureTex(Texture2D tex, int w, int h) Creates (or resizes) a Texture2D of the specified width/height, configured for point-sampling and clamped wrap mode. Returns an existing texture if size already matches.
ApplyToTexture(Texture2D tex, float[] buffer, (float min,float max) range, Gradient gradient) Uploads a scalar buffer into a texture, mapping values from range to [0..1] and coloring them using gradient.
DrawRow(string rowTitle, Texture2D tex, bool autoFit, float windowWidth, int previewScale) Draws a label and a scaled texture row inside an editor scroll view. Handles auto-fit or fixed preview scale.
SavePng(Texture2D tex, string nameBase) Opens a Save File Panel to export the current texture as a PNG file. Uses AssetDatabase.Refresh() after writing.

Typical usage

Both heatmap windows follow the same pattern:

_tex = NoiseEditorHelper.EnsureTex(_tex, _width, _height);
NoiseEditorHelper.ApplyToTexture(_tex, _buffer, (0f, 1f), _gradient);

NoiseEditorHelper.DrawRow("My Preview", _tex, _autoFit, position.width, _previewScale);

if (GUILayout.Button("Save PNG"))
    NoiseEditorHelper.SavePng(_tex, "My Heatmap");

This gives you a one-line API for drawing each preview row and exporting it.

Dependencies

  • UnityEditor (EditorGUILayout, EditorUtility, AssetDatabase)
  • UnityEngine (Texture2D, Gradient, Color)
