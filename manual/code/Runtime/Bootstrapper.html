Bootstrapper

Source: ./Runtime/Bootstrapper.cs

Overview

Handles the initial bootstrapping of the application, ensuring essential settings are applied and that the correct scenes load when the application starts.

At startup it reads the static values in CoreFrameworkSettings (populated by CoreFrameworkPreferences + CoreFrameworkProjectSettings via CoreFrameworkSettingInitialization) and uses them to load the Boot Scene and Start Scene.

How it works

The class uses Unity’s [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)] to run a static Init() method before the first scene loads.

Flow

  1. Editor

    • Gets the currently loaded editor scene.
    • If a Boot Scene is configured and not yet loaded:
      • Unloads the current editor scene.
      • Loads the Boot Scene.
    • Then re-adds the editor scene additively so you can keep working.

  2. Player (built game)

    • If Boot Scene is configured and not yet loaded, loads it.
    • If Start Scene is configured and not yet loaded, loads it additively after Boot Scene.
[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
private static void Init()
{
#if UNITY_EDITOR
    var currentlyLoadedEditorScene = SceneManager.GetActiveScene();
#endif

    if (string.IsNullOrWhiteSpace(CoreFrameworkSettings.BootScene) ||
        string.Equals(CoreFrameworkSettings.BootScene, "None", StringComparison.Ordinal)) return;

    // Load Boot Scene if not loaded
    if (!SceneManager.GetSceneByName(CoreFrameworkSettings.BootScene).isLoaded)
    {
#if UNITY_EDITOR
        SceneManager.UnloadSceneAsync(currentlyLoadedEditorScene);
#endif
        SceneManager.LoadScene(CoreFrameworkSettings.BootScene);
    }

#if UNITY_EDITOR
    // Additively reload the original editor scene
    SceneManager.LoadSceneAsync(currentlyLoadedEditorScene.name, LoadSceneMode.Additive);
#else
    // In built player, load Start Scene additively
    if (!string.IsNullOrWhiteSpace(CoreFrameworkSettings.StartScene) &&
        !string.Equals(CoreFrameworkSettings.StartScene, "None", StringComparison.Ordinal) &&
        !SceneManager.GetSceneByName(CoreFrameworkSettings.StartScene).isLoaded)
    {
        SceneManager.LoadSceneAsync(CoreFrameworkSettings.StartScene, LoadSceneMode.Additive);
    }
#endif
}

Why it matters

  • Editor convenience: lets you test Boot + Start scene flow without manually loading scenes.
  • Consistent startup: in builds, automatically loads Boot Scene, then Start Scene additively if configured.

Notes

  • Scene names must be in File → Build Settings… for Unity to load them by name.
  • Boot Scene and Start Scene values come from Project Settings → Core Framework → Settings.
