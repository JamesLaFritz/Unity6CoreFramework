ulong2

Source: ./Runtime/Mathmatics/ulong2.cs

Overview

ulong2 is a lightweight pair of 64-bit unsigned integers designed to mirror Unity.Mathematics’ vector types (int2, uint2, etc.). It supports rich construction, implicit conversions, component-wise operators, comparisons returning bool2, bitwise ops, swizzles, and simple math helpers.

Used throughout CoreFramework where a compact 128-bit lane is convenient (e.g., hashing & noise).

Constructors & Conversions

  • Direct: new ulong2(ulong x, ulong y)
  • Broadcast: new ulong2(ulong v) (sets both x and y)
  • From signed/float vectors: new ulong2(int2|float2|double2|long2|bool2)
  • Implicit from: uint2, int2, float2, double2, bool2, and the scalar forms (ulong/long/uint/int/float/double/bool)
  • Explicit to: uint2, int2, float2, double2
    (scalar casts use x component)

Also includes tuple sugar:

ulong2 a = (1UL, 2UL);       // implicit (ulong,ulong) -> ulong2
(ulong x, ulong y) t = a;    // deconstruct back to tuple

Operators (component-wise)

  • Arithmetic: + - * / % (with ulong/uint scalar overloads)
  • Unary: ++ -- + - (note: unary - uses wraparound semantics on ulong)
  • Bitwise: & | ^ ~ << >>
  • Comparisons → bool2: == != < <= > >=

Swizzles

A full set of 2- and 4-component read-only swizzles (xxxy, xxyy, yxxx, …) plus writable 2-component pairs:

var p = new ulong2(10, 20);
ulong2 a = p.xy;     // (10,20)
p.yx = (1UL, 2UL);   // now p = (2,1)

Math helpers (static)

ulong2 min(ulong2 a, ulong2 b)
ulong2 max(ulong2 a, ulong2 b)
ulong2 clamp(ulong2 v, ulong2 min, ulong2 max)
ulong   dot(ulong2 a, ulong2 b)

Hash helpers (CoreFramework.Mathematics.Math)

ulong  Math.hash(ulong2 v)                       // 64-bit hash of both lanes
ulong2 Math.hashwide(ulong2 v)                   // wide hash (per-lane)
ulong  Math.shuffle(ulong2 left, ulong2 right, ShuffleComponent x)
ulong2 Math.shuffle(ulong2 left, ulong2 right, ShuffleComponent x, ShuffleComponent y)
ulong4 Math.shuffle(ulong2 left, ulong2 right, ShuffleComponent x, y, z, w)

Example

using CoreFramework.Mathematics;
using Unity.Mathematics;

var a = new ulong2(123UL, 456UL);
var b = (ulong2) new uint2(7, 9);

ulong2 sum = a + b;          // (130, 465)
bool2  gt = a > b;           // (true, true)

ulong  h  = Math.hash(sum);  // compact 64-bit hash
ulong2 hw = Math.hashwide(a);

Notes

  • BurstCompile attribute is present; operators and helpers are inlined and Burst-friendly.
  • GetHashCode() delegates to Math.hash(this).
