ulong4

Source: ./Runtime/Mathematics/ulong4.cs

Overview

ulong4 is a lightweight four-component vector of 64-bit unsigned integers designed to mirror Unity.Mathematics’ vector types (int4, uint4, etc.). It supports rich construction, implicit conversions, component-wise operators, comparisons returning bool4, bitwise ops, swizzles, and simple math helpers.

Originally added to support 256-bit noise hashing and crypto-style procedural generation (full ChaCha rounds), it lays the groundwork for larger, more secure hashes if needed. In CoreFramework most 128-bit use cases are handled by ulong2, but you can use ulong4 wherever you want a deterministic 256-bit value packaged in a single type.

Constructors & Conversions

  • Direct: new ulong4(ulong x, ulong y, ulong z, ulong w)
  • Broadcast: new ulong4(ulong v) (sets all four components)
  • From signed/float vectors: new ulong4(int4|float4|double4|long4|bool4) (componentwise conversion)
  • Implicit from: uint4, int4, float4, double4, bool4, and the scalar forms (ulong/long/uint/int/float/double/bool)
  • Explicit to: uint4, int4, float4, double4
    (scalar casts use x component)

Also includes tuple sugar:

ulong4 a = (1UL, 2UL, 3UL, 4UL);           // implicit (ulong,ulong,ulong,ulong) -> ulong4
(ulong x, ulong y, ulong z, ulong w) t = a; // deconstruct back to tuple

Operators (component-wise)

  • Arithmetic: + - * / % (with ulong/uint scalar overloads)
  • Unary: ++ -- + - (note: unary - uses wraparound semantics on ulong)
  • Bitwise: & | ^ ~ << >>
  • Comparisons → bool4: == != < <= > >=

Swizzles

A full set of 2-, 3-, and 4-component read-only swizzles (xxxy, xxyy, yxxx, zwxy, …) plus writable 2-component pairs:

var p = new ulong4(10, 20, 30, 40);
ulong2 a = p.xy;        // (10,20)
p.yx = (1UL, 2UL);      // now p = (2,1,30,40)

Math helpers (static)

ulong4 min(ulong4 a, ulong4 b)
ulong4 max(ulong4 a, ulong4 b)
ulong4 clamp(ulong4 v, ulong4 min, ulong4 max)
ulong   dot(ulong4 a, ulong4 b)

Hash helpers (CoreFramework.Mathematics.Math)

ulong  Math.hash(ulong4 v)                       // 64-bit hash of all lanes
ulong4 Math.hashwide(ulong4 v)                   // wide hash (per-lane)
ulong  Math.shuffle(ulong4 left, ulong4 right, ShuffleComponent x)
ulong2 Math.shuffle(ulong4 left, ulong4 right, ShuffleComponent x, ShuffleComponent y)
ulong4 Math.shuffle(ulong4 left, ulong4 right, ShuffleComponent x, y, z, w)

Example

using CoreFramework.Mathematics;
using Unity.Mathematics;

var a = new ulong4(1UL, 2UL, 3UL, 4UL);
var b = (ulong4) new uint4(7, 9, 11, 13);

ulong4 sum = a + b;          // (8,11,14,17)
bool4  gt  = a > b;          // (false,false,false,false)

ulong  h  = Math.hash(sum);  // compact 64-bit hash
ulong4 hw = Math.hashwide(a);

Notes

  • BurstCompile attribute is present; operators and helpers are inlined and Burst-friendly.
  • GetHashCode() delegates to Math.hash(this).
