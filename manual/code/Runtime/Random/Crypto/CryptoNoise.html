CryptoNoise

Source: ./Runtime/Random/Crypto/CryptoNoise.cs

Overview

CryptoNoise is a static helper that generates deterministic, noise-based keys for experimental cryptographic or large-key procedural generation scenarios.
It builds on Core Framework’s noise functions (SquirrelNoise32Bit, SquirrelNoise64Bit, and HashBasedNoiseUtils) to produce uint4 or ulong[] key material seeded with ChaCha-inspired quarter rounds.

Although full 256-bit noise hashing hasn’t been implemented in CoreFramework yet, CryptoNoise lays the groundwork for it by combining multiple noise calls and Prime constants to mimic cryptographic diffusion.

Responsibilities

  • Generate 4×32-bit or 4×64-bit pseudo-random values for use as keys.
  • Provide overloads for uint/ulong positions and seeds.
  • Use different NoiseType variants (ChaChaQuarterRoundSimple/Advanced) to diversify the key stream.
  • Return deterministic keys for the same position+seed input.

Methods

Method Description
GenerateKey(uint seed) Returns a uint4 key based on a simple ChaCha noise seed.
GenerateKey(uint position, uint seed) Returns a uint4 key using 32-bit index+seed, combining simple and advanced ChaCha rounds.
GenerateKey(ulong seed) Same as above but using a 64-bit seed.
GenerateKey(ulong position, ulong seed) Returns a uint4 key by combining multiple noise calls with Prime constants.
GenerateKey64(uint seed) / GenerateKey64(uint position, uint seed) / GenerateKey64(ulong seed) / GenerateKey64(ulong position, ulong seed) Return an array of four 64-bit unsigned integers as the key material.

Usage Example

using CoreFramework.Random.Crypto;
using Unity.Mathematics;

public class KeyExample
{
    public void DemoKeys()
    {
        // Simple 32-bit key
        uint4 key32 = CryptoNoise.GenerateKey(123u);
        
        // 32-bit key from position + seed
        uint4 key32Pos = CryptoNoise.GenerateKey(42u, 999u);

        // 64-bit key material
        ulong[] key64 = CryptoNoise.GenerateKey64(42UL, 999UL);

        UnityEngine.Debug.Log($"Key32: {key32}");
        UnityEngine.Debug.Log($"Key64 parts: {string.Join(\", \", key64)}");
    }
}

This will yield the same keys every time for the same inputs, which is useful for procedural or reproducible setups.

Behavior Notes

  • Keys are deterministic but not cryptographically secure — they’re for hashing / PCG experiments, not for real encryption.
  • Uses CoreFramework’s Prime1, Prime2, and Prime3 constants to spread input entropy across multiple rounds.
  • Can be extended to output a ulong4 once full 256-bit noise hashing is implemented.
