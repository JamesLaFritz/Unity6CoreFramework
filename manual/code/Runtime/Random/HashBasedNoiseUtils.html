HashBasedNoiseUtils

Source: ./Runtime/Random/HashBasedNoiseUtils.cs

Overview

HashBasedNoiseUtils is a Burst-compiled static helper class providing the building blocks for all of CoreFramework’s hashing-based noise functions.
It exposes constants, bit-mangling utilities, ChaCha-inspired mixing rounds, Perlin gradients, fade curves, cellular helpers, and normalization helpers.

This class underpins all SquirrelNoise32/64/128 implementations, Cellular/Worley evaluation, and CryptoNoise key generation.

Responsibilities

  • Constants: Golden ratios, MurmurHash3 finals, ChaCha primes, large primes, simplex skew/unskew factors.
  • 32-bit mixing: ShiftXOR, BalancedMix, Rotational, ChaCha quarter rounds.
  • 64-bit mixing: Same patterns extended to 64-bit lanes.
  • Float conversions: Unsigned → [0,1] and [-1,1].
  • Perlin core: Gradient functions, fade, fade derivatives, and PerlinWithDeriv for analytic gradients.
  • Cellular core: Distance metrics, F1/F2 result structs, vein intensity remaps, and F1 normalization helpers.

Perlin Core

  • Fade(t) and FadeDeriv(t) — quintic fade curve and derivative.
  • Perlin(...) — 2D & 3D corner-hash driven Perlin noise.
  • PerlinWithDeriv(...) — 2D & 3D with analytic gradient out-parameters.
  • Grad2Vec(hash) / Grad3Vec(hash) — gradient direction lookups.

Cellular / Worley Core

  • CellularDistance enum — Euclidean, Manhattan, Chebyshev.
  • Cellular2DResult & Cellular3DResult readonly structs.
  • CellularVein01 & CellularVeinExp01 — vein/edge intensities.
  • NormalizeF101 & NormalizeF1Inv01 — jitter/metric-aware F1 normalization.

Example

using CoreFramework.Random;

uint hash = HashBasedNoiseUtils.MangledBitsBalancedMix(123, 456);

float fade = HashBasedNoiseUtils.Fade(0.5f);

var cell = new HashBasedNoiseUtils.Cellular2DResult(0.1f, 0.3f, new float2(0.5f,0.5f), new int2(1,1));
float edge = HashBasedNoiseUtils.CellularVein01(cell, 0.12f);

Notes

  • All methods are [MethodImpl(MethodImplOptions.AggressiveInlining)] and [BurstCompile] where applicable.
  • Designed for deterministic, reproducible hashing and noise across Unity jobs and Burst.
