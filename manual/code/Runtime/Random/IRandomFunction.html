IRandomFunction<TIndex, TSeed>

Source: ./Runtime/Random/IRandomFunction.cs

Overview

IRandomFunction<TIndex, TSeed> defines the interface contract for any deterministic random function or RNG used within CoreFramework.
It abstracts over index-based and seed-based noise functions (e.g. SquirrelNoise, SecureNoise) so that both stateless and stateful RNGs can be plugged into the same systems.

Implementations (like SquirrelNoise64Rng) provide a deterministic, Burst-friendly, and reproducible source of random values for procedural content generation.

Key Responsibilities

  • Exposes the Seed and Position (or index) that drive random sequence generation.
  • Provides a consistent API to:
    • Reset or reseed the generator.
    • Query the current Seed value.
    • Step through a sequence deterministically.
    • Retrieve single values or structured values (vectors, rotations).
  • Designed to work with Unity.Mathematics types and Burst.

Typical Interface Members

Although the interface is generic, your implementing RNGs usually include:

Member Purpose
Seed { get; } Underlying seed controlling randomness.
Position Current index/position (for sequential RNGs).
ResetSeed(seed, position) Re-initialize seed & index.
Range(min, max) Get a random value in a specified range.
Value Normalized float [0,1] per step.
InsideUnitSphere / OnUnitSphere Random directions/points.
Rotation / RotationUniform Random quaternions.
Uint128 / Uint64 etc. Raw integer lanes from noise.

Concrete examples can be seen in SquirrelNoise64Rng.

Example Usage

using CoreFramework.Random;

public class Example
{
    public void Demo(IRandomFunction<ulong, ulong> rng)
    {
        // reseed
        rng.ResetSeed(1234UL);

        // get normalized float
        float val = rng.Value;

        // random int range
        int dice = rng.Range(1, 7);

        // random rotation
        var q = rng.RotationUniform;
    }
}
