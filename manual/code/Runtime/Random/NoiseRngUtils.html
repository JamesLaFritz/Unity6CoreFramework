NoiseRngUtils

Source: ./Runtime/Random/NoiseRngUtils.cs

Overview

NoiseRngUtils is a helper utility class that bundles common patterns and convenience functions for CoreFramework’s noise-based random number generators.
It provides a shared toolkit for implementing IRandomFunction<TIndex,TSeed> RNGs such as SquirrelNoise32Rng and SquirrelNoise64Rng.

Use it to reduce boilerplate when writing new RNGs: the static methods encapsulate repeated math for range mapping, normalized float conversions, vector sampling, and direction/rotation utilities.

Key Responsibilities

  • Value mapping: Convert raw noise lanes to normalized floats or scaled ranges.
  • Sampling helpers: Produce inside/on unit sphere directions, 2D/3D random points, quaternions.
  • Utility sugar: Step or reseed your RNG consistently across implementations.
  • Performance: All methods are [MethodImpl(MethodImplOptions.AggressiveInlining)] and Burst-friendly.

Typical Methods

Method Purpose
float To01(uint v) Convert uint noise lane to [0,1].
float Range01(uint v, float min, float max) Map noise lane to [min,max].
float2 Direction2D(uint a, uint b) Random 2D unit direction from two lanes.
float3 Direction3D(uint a, uint b, uint c) Random 3D unit direction from three lanes.
quaternion RotationUniform(uint a, uint b, uint c, uint d) Uniform random quaternion from four lanes.

(Exact signatures depend on the utility version you have, but these are the patterns you’ll find.)

Example Usage

using CoreFramework.Random;

public class Example
{
    public void Demo()
    {
        // raw lanes from a noise RNG
        uint a = 123456789u;
        uint b = 987654321u;

        // convert to normalized float
        float val = NoiseRngUtils.To01(a);

        // get a random direction
        var dir2 = NoiseRngUtils.Direction2D(a, b);

        // map to a custom range
        float roll = NoiseRngUtils.Range01(a, 1f, 6f);
    }
}
