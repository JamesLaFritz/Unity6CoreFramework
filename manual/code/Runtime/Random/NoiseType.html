NoiseType

Source: ./Runtime/Random/NoiseType.cs

Overview

NoiseType is an enumeration that specifies which mixing / hashing algorithm a CoreFramework noise generator or RNG should use.
It acts as a runtime switch inside SquirrelNoise32Bit, SquirrelNoise64Bit, and their RNG wrappers, allowing you to pick between multiple bit-mangling strategies (balanced Murmur3 style, rotational, ChaCha quarter rounds, etc.).

This gives you fine control over the statistical distribution and performance characteristics of your procedural noise / random functions.

Members

Enum Value Description
MangledBitsShiftXOR A fast, old-school XOR+shift+Murmur mix.
MangledBitsBalancedMix Balanced Murmur3-inspired mixing (default).
MangledBitsRotational Rotational bit-mangling variant for extra diffusion.
ChaChaQuarterRoundSimple Simple ChaCha-inspired quarter-round.
ChaChaQuarterRoundAdvanced Full ChaCha-style quarter-round with extra mixing.

(Exact names depend on the version of NoiseType.cs you have; these are the standard ones.)

Typical Usage

using CoreFramework.Random;

public class Example
{
    public void Demo()
    {
        // pick a mixing style
        NoiseType type = NoiseType.ChaChaQuarterRoundAdvanced;

        // feed it into a noise function
        uint noise = SquirrelNoise32Bit.Get1DNoise(1234, 5678, type);

        // or into a noise-based RNG
        var rng = new SquirrelNoise32Rng(0u, 123u, type);
        float value = rng.Value; // uses selected NoiseType internally
    }
}
