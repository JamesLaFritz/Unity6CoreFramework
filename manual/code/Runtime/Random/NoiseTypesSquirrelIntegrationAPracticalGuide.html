Noise Types & Squirrel Integration — A Practical Guide

A compact, production-oriented reference that explains what each noise is, how its knobs shape results, and exactly how it maps to SquirrelNoise32Bit / SquirrelNoise64Bit APIs and HashBasedNoiseUtils cores.

Shared knobs (you’ll see them everywhere)

  • Amplitude (amp): vertical scale of the output.
  • Frequency (freq): feature size (↑freq → smaller features). Often scale the input position instead.
  • Octaves: how many stacked layers you sum; each octave is higher freq and lower amp.
  • Lacunarity: frequency multiplier per octave (≈ 2.0).
  • Gain / Persistence: amplitude multiplier per octave (≈ 0.5).

Think of an octave stack (fBm) as your “how bumpy” control; the base noise you stack (Perlin, Simplex, Value, Worley) sets the character of those bumps.

Core bases

Perlin / Simplex (gradient noise)

  • What: Pseudo-random gradients at lattice corners, faded and blended. Simplex uses skewed simplices (triangles/tetrahedra), fewer samples in >2D.
  • Feels like: Smooth, band-limited hills; Simplex is slightly crisper and more isotropic.
  • Range: ~[-1, 1].
  • Continuity: C1 (value + first derivative continuous).
  • Where to use: Terrain height, masks, clouds, normals (with analytic gradients).
  • In Squirrel Noise:
    • 2D/3D value: SquirrelNoise32Bit.Perlin(...), SquirrelNoise64Bit.Perlin(...)
    • Analytic gradient: PerlinWithDeriv(...) (2D/3D) on both 32/64
    • Simplex cores: Simplex2DCore(...), Simplex3DCore(...) (hash-callback based)

Value noise (hash-smoothed)

  • What: Hash lattice values and smooth-interpolate with Fade.
  • Feels like: Perlin-ish; trivial to drive from stateless Squirrel hashes.
  • Note: Already using hash-driven gradients/values under Perlin/Simplex; value noise fits the same pattern if you ever want it.
  • In Squirrel Noise:
    • 1D/2D/3D/4D value: .Get1DNoise(...), .Get2DNoise(...) .Get3DNoise(...) .Get3DNoise(...) .Get4DNoise(...) both 32/64

Worley / Cellular

  • What: Distance to nearest / 2nd-nearest feature points per cell → cells, cracks, pebbles, veins.
  • Not a heightfield by itself: You usually remap (invert, edge extract) or combine with other fields.
  • In Squirrel Noise: .Cellular2D(...), .Cellular3D(...), helpers (CellularF1, CellularF2MinusF1, CellularEdge01, CellularEdgeExp01, CellularEdgeSigned) both 32/64.

Fractal “variants” (post-process + stacking)

fBm (Fractional Brownian Motion)

  • What: Sum octaves of a base noise at increasing frequency and decreasing amplitude.
  • Feels like: Classic rolling mountains; self-similar detail.
  • Knobs: octaves, lacunarity≈2, gain≈0.5, base freq/amp.
  • In Squirrel Noise: .FBm(...) both 32/64.

Billow

  • What: abs(base(p)) per octave, then re-center.
  • Feels like: Puffy pillows / clouds.
  • In Squirrel Noise: .Billow(...) both 32/64.

Ridge (Ridged-multifractal)

  • What: r = 1 - abs(base(p)), sharpen via power/bias, weight by previous octave.
  • Feels like: Sharp crests, deep valleys.
  • In Squirrel Noise: .Ridge(...) both 32/64.

Domain warping

  • What: Displace input coords by a low-frequency vector field before sampling: p' = p + A * W(p)
  • Feels like: Twisted, meandering structures; breaks grid repetition.
  • In Squirrel Noise: .DomainWarp(...) both 32/64.

Analytical derivatives (∇noise)

  • What: Closed-form gradient of Perlin with your exact Fade/grad definitions.
  • Use: Slope-aware detail, normals, flow/advection, curl fields.
  • In Squirrel Noise: PerlinWithDeriv(...) (2D/3D) on both 32/64. Aliases: ValueAndGrad(...). Approximation: GradientCentral(...) (finite differences).

“Uber Noise” (No Man’s Sky-style composition)

  • What: Two domain warps → fBm base → subtract a ridged component → clamp/normalize.
  • Feels like: Big shapes with believable micro detail that holds up close.
  • In Squirrel Noise: .UberNoise(...) on both 32/64.

Stateless integration pattern (how it all plugs together)

  • Entropy core: NoiseType picks the hash/mixer (see below).
  • Corner/feature hashes: 32-bit: Get1D/2D/3DNoise; 64-bit: GetUInt64, Get2DNoise(...) etc.
  • Per-octave reseed: MixOctave(seed, i) (32/64 variants).
  • Gradient/value cores: HashBasedNoiseUtils.Perlin(...), ...PerlinWithDeriv(...), Simplex2DCore/3DCore.
  • Cellular: Cellular2D/3D returns F1/F2 + feature/cell info; remap with helpers.

NoiseType (the hash mixer)

enum controls how indices/seeds scramble into pseudo-random bits:

  • Use by default: MangledBitsBalancedMix
  • Alternatives: MangledBitsShiftXOR, MangledBitsRotational (slightly different dispersion), ChaChaQuarterRoundSimple/Advanced (strong diffusion)
  • Mental model: Swapping NoiseType changes micro-texture/correlation, not the high-level algorithm (Perlin/Simplex/Cellular).

Cellular = two practical buckets

Wormy (veins, tunnels, tendrils)

  • Metric: Euclidean
  • Jitter: 0.75–1.0 (organic)
  • Frequency: low (e.g. 0.002–0.01)
  • Value: use edges → F2 - F1 then invert/soften
  • Warp: optional low-freq warp to bend paths

Minimal recipe (2D → [-1,1]):

float WorleyWormy2D(float2 P, ulong seed, float freq=0.005f, float jitter=1.0f, float edgeWidth=0.1f)
{
    var r = SquirrelNoise64Bit.Cellular2D(P, seed, frequency: freq, jitter: jitter,
        metric: HashBasedNoiseUtils.CellularDistance.Euclidean);
    float vein01 = 1f - math.saturate((r.F2 - r.F1) / edgeWidth);
    return vein01 * 2f - 1f;
}

Blocky (tiles, bricks, city grids)

  • Metric: Manhattan (diamond) or Chebyshev (square)
  • Jitter: 0.0–0.25 (anchored)
  • Frequency: 0.003–0.02
  • Value: F1 for fill, F2−F1 for edges; step/quantize for hard panels

Minimal recipe (2D):

float WorleyBlocky2D(float2 P, ulong seed, float freq=0.01f, float jitter=0.1f)
{
    var r = SquirrelNoise64Bit.Cellular2D(P, seed, frequency: freq, jitter: jitter,
        metric: HashBasedNoiseUtils.CellularDistance.Chebyshev);
    float edges01 = 1f - math.saturate((r.F2 - r.F1) / 0.1f);
    return edges01 * 2f - 1f;
}

Fractal defaults (good starting points)

fBm

  • octaves=5–7, lacunarity=2, gain=0.5, normalize output.
  • Bigger features: ↓freq or ↓octaves.
  • Finer detail: ↑octaves (keep normalization).

Billow

  • Same as fBm; often gain=0.55–0.65.
  • Too round? Mix a bit of plain fBm: 0.7*Billow + 0.3*fBm.

Ridge

  • Start: ridgeOffset≈1.0, ridgeSharpness=2–3, frequency ×1.2–1.6 vs base.
  • Too spiky? ↓sharpness or ↓freq.

Mixing Cellular with fractals

  • Wormy rivers over terrain

    1. height = FBm(Perlin, p, seed, …)
    2. vein01 = CellularEdge01(...) (Euclidean, high jitter)
    3. height -= vein01 * carveDepth
    4. Optional: warp the vein sampling position with a very low-freq warp.

  • Blocky biomes

    1. Cellular2D with Chebyshev, jitter≈0.05
    2. Per-cell ID: Get2DNoise(r.Cell.x, r.Cell.y, seed) → pick biome params
    3. Evaluate fBm/Billow/Ridge with that per-cell seed.

  • Road masks Threshold F2−F1 < w, optionally thin/skeletonize.

Domain warping heuristics

  • Big bend, small twist: keep warp amplitude modest (0.2–0.8), warp freq lower than the value freq.
  • Two-scale warp: slow/strong warp for macro shape, then faster/weaker warp for mid detail.
  • Too torn: reduce warp freq or amplitude.

Handy snippets

1) Generic vein mask (01) from a Cellular result

[MethodImpl(MethodImplOptions.AggressiveInlining)]
static float WorleyVein01(in HashBasedNoiseUtils.Cellular2DResult r, float edgeWidth = 0.1f)
    => 1f - math.saturate((r.F2 - r.F1) / edgeWidth);

2) 3D wormy with small fractal detail

float Worm3D(float3 P, ulong seed)
{
    var r = SquirrelNoise64Bit.Cellular3D(P, seed, frequency: 0.006f, jitter: 0.9f);
    float vein01 = 1f - math.saturate((r.F2 - r.F1) / 0.12f);
    float detail = 0.25f * SquirrelNoise64Bit.FBm(P * 1.8f, seed, octaves: 4, gain: 0.55f);
    return math.saturate(vein01 + detail);
}

3) Blocky tiles with per-cell variation

float BlockyTile(float2 P, ulong seed)
{
    var r = SquirrelNoise64Bit.Cellular2D(P, seed, frequency: 0.01f, jitter: 0.05f,
        metric: HashBasedNoiseUtils.CellularDistance.Chebyshev);

    // Per-cell seed for interior variation:
    ulong cellSeed = SquirrelNoise64Bit.GetCellSeed2D(r.Cell, seed);
    float tile = SquirrelNoise64Bit.FBm(new float3(P, 0), cellSeed, octaves: 4, gain: 0.6f);

    float edges = 1f - math.saturate((r.F2 - r.F1) / 0.08f);
    return math.clamp(tile * 0.7f + edges * 0.3f, -1f, 1f);
}

Final tuning cheatsheet

  • Straighter structure: ↓jitter, use Manhattan/Chebyshev.
  • More organic curves: ↑jitter, keep Euclidean, add 1–2 domain warps.
  • Thinner veins/roads: ↓edgeWidth (or ↑k in exponential remap).
  • Bigger cells/roads: ↓frequency (remember F1/F2 are in cell units at your sampling freq).
  • Too noisy: lower the value octaves first; keep warps smooth/low-freq.
  • Terrain mushy: add a small Ridge layer (2–3 octaves, mix 0.2–0.4).

Ranges, seeds, performance notes

  • Ranges: Perlin/Simplex are ~[-1,1] (cores match this); Cellular helpers return 0..1 or [-1,1] as named.
  • Seeds: Use MixOctave(seed, i) for decorrelated octave seeds; 32/64 versions exist.
  • NoiseType: Keep MangledBitsBalancedMix unless you need a different micro-texture profile.
  • Unity Burst: All hot paths are AggressiveInlining; keep branches minimal (already do). Prefer float math; avoid allocations.

TL;DR

  • Choose base: Perlin/Simplex for smooth, Worley for cells.
  • Shape with fBm/Billow/Ridge.
  • Warp for richness.
  • Use PerlinWithDeriv for slope-aware tricks.
  • Drive everything from stateless Squirrel hashes; swap NoiseType if you want different bit-mix flavor.
