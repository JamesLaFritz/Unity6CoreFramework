SquirrelNoise128

Source: ./Runtime/Random/SquirrelNoise128.cs

Overview

SquirrelNoise128 provides 128-bit lane hashing utilities used to build deterministic pseudo-random 1D/2D/3D/4D noise. It works with ulong2 (two 64-bit lanes) and returns either packed 128-bit results or reduced 64/32-bit scalars. Float helpers convert to [0,1] or [-1,1] ranges.

Default algorithm: NoiseType.ChaChaQuarterRoundSimple (see NoiseType enum). Internally, hashing mixes constants like the 64-bit golden-ratio prime.

Core functions

128- / 64-bit

ulong2 GetUInt128(ulong2 index, ulong2 seed, NoiseType type = Default)
ulong  GetUInt64 (ulong2 index, ulong2 seed, NoiseType type = Default)  // OR of both lanes

Integer noise (returns uint)

uint Get1DNoise(ulong2 index,                 ulong2 seed, NoiseType type = Default)
uint Get2DNoise(ulong2 x, ulong2 y,           ulong2 seed, NoiseType type = Default)
uint Get3DNoise(ulong2 x, ulong2 y, ulong2 z, ulong2 seed, NoiseType type = Default)
uint Get4DNoise(ulong2 x, ulong2 y, ulong2 z, ulong2 w, ulong2 seed, NoiseType type = Default)

(2D/3D/4D combine coordinates with 64-bit primes before hashing.)

Usage examples

2D tileable sampling (integers-in, floats-out)

using CoreFramework.Mathematics;
using CoreFramework.Random;

int w = 256, h = 256;
var seed = new ulong2(12345UL, 67890UL);

for (int y = 0; y < h; y++)
for (int x = 0; x < w; x++)
{
    // pack coordinates into ulong2 lanes if desired; here we just broadcast
    var X = new ulong2((ulong)x);
    var Y = new ulong2((ulong)y);

    float v01 = SquirrelNoise128.Get2DNoise01(X, Y, seed);         // [0,1]
    // ...write to texture / heightmap...
}

3D volume strip (compatible with the editor heatmaps)

var seed = (ulong2)(42UL);
for (int y = 0; y < H; y++)
for (int x = 0; x < W; x++)
for (int z = 0; z < W; z++)
{
    float v = SquirrelNoise128.Get3DNoise01((ulong2)(ulong)x, (ulong2)(ulong)y, (ulong2)(ulong)z, seed);
    // pack at column = z*W + x, row = y
}

Notes

  • Functions are MethodImplOptions.AggressiveInlining for Burst friendliness.
  • GetUInt64 reduces GetUInt128 by OR’ing lanes; pick the variant appropriate for your distribution needs.
  • Float mapping helpers use HashBasedNoiseUtils.ToZeroToOne / ToNegOneToOne.
