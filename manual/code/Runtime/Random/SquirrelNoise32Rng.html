SquirrelNoise32Rng

Source: ./Runtime/Random/SquirrelNoise32Rng.cs

Overview

SquirrelNoise32Rng is a lightweight, stateless-style RNG façade built on the 32-bit Squirrel noise core. Given a Seed and Position, it produces reproducible random values (scalars, vectors, rotations) by advancing the Position and hashing it with the chosen NoiseType. It’s ideal for deterministic gameplay, spawning, and procedural generation where you want repeatable streams without maintaining a heavy PRNG state.

Defaults use NoiseType.MangledBitsBalancedMix. See the guides for trade-offs and picking a noise type.

Examples

using CoreFramework.Random;
using Unity.Mathematics;

var rng = new SquirrelNoise32Rng(seed: 1337U);

// Scalars
uint  r = rng.Uint32;
float u = rng.Value;
bool  hit = rng.Chance(0.1f);

// Ranges
int   i = rng.Range(-10, 10);
float f = rng.Range(-1f, 1f);

// Vectors & rotations
float3 dir = rng.Direction3D;
float3 p   = rng.InsideUnitSphere;
quaternion q = rng.Rotation;

// Perlin using the RNG’s seed/type
float n2 = rng.Perlin(12.5f, 7.25f);
float n3 = rng.Perlin(1f, 2f, 3f);

Notes

  • Deterministic for the same (Seed, Type) and read order; each getter advances Position internally.
  • Designed for Burst: methods are small, inline-friendly, and allocation-free.
  • Use ResetSeed(...) to reuse an RNG with a different seed and/or starting position.
