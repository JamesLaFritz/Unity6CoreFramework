SquirrelNoise64Bit

Source: ./Runtime/Random/SquirrelNoise64Bit.cs

Overview

SquirrelNoise64Bit is the 64-bit, hash-based noise core for CoreFramework.
It exposes fast, seedable 1D–4D integer noise returning ulong, normalized float variants ([0,1] and [-1,1]), Perlin wrappers (2D/3D with optional analytic derivatives), and Cellular/Worley helpers using 64-bit mixing.

Defaults use DefaultNoiseType (currently MangledBitsBalancedMix) — see the guides below for details and trade-offs.

Examples

using CoreFramework.Random;

// integer
ulong h = SquirrelNoise64Bit.Get3DNoise(12, 7, 4, seed: 1337UL);

// normalized float
float n = SquirrelNoise64Bit.Get2DNoise01(128UL, 64UL, seed: 42UL);

// Perlin + derivative
float v = SquirrelNoise64Bit.PerlinWithDeriv(3.2f, -1.1f, seed: 9UL, out float2 d);

// wide keys
ulong2 k128 = SquirrelNoise64Bit.GetUInt128(5UL, 99UL);

Notes

  • All methods are [MethodImplOptions.AggressiveInlining] and [BurstCompile] ready.
  • Works statelessly — you can query any index without sequential calls.
  • Use NoiseType to switch between bit-mix strategies (MangledBits, ChaCha, etc.).
