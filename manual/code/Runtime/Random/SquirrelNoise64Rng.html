SquirrelNoise64Rng

Source: ./Runtime/Random/SquirrelNoise64Rng.cs

Overview

SquirrelNoise64Rng is a lightweight, stateless-style RNG façade built on the 64-bit Squirrel noise core. Given a Seed and Position, it produces reproducible random values (scalars, vectors, rotations) by advancing the Position and hashing it with the chosen NoiseType. It’s ideal for deterministic gameplay, spawning, and procedural generation where you want repeatable streams without maintaining a heavy PRNG state.

Defaults use NoiseType.ChaChaQuarterRoundSimple. See the guides for trade-offs and picking a noise type.

Examples

using CoreFramework.Random;
using Unity.Mathematics;

var rng = new SquirrelNoise64Rng(seed: 1234UL);

// Scalars
uint  r32 = rng.Uint32;
ulong r64 = rng.Uint64;
float u01 = rng.Value;
bool  hit = rng.Chance(0.25f);

// Ranges
int   i = rng.Range(-10, 10);
float f = rng.Range(-1f, 1f);

// Vectors & rotations
float3 dir = rng.Direction3D;
float3 p   = rng.InsideUnitSphere;
quaternion q = rng.Rotation;

// Wide ints
ulong2 k = rng.Uint128;

// Perlin using the RNG’s seed/type
float n2 = rng.Perlin(12.5f, 7.25f);
float n3 = rng.Perlin(1f, 2f, 3f);

Notes

  • Deterministic for the same (Seed, Type) and read order; each getter advances Position internally.
  • Designed for Burst: methods are small, inline-friendly, and allocation-free.
  • Use ResetSeed(...) to reuse an RNG with a different seed and/or starting position.
