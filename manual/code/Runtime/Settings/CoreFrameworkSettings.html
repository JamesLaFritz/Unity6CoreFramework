CoreFrameworkSettings

Source: ./Runtime/Settings/CoreFrameworkSettings.cs

Overview

A runtime static container that other systems read to determine startup scenes and debug display preferences.
Values are populated in the Editor by CoreFrameworkSettingInitialization, which mirrors:

  • Project-wide scene choices from CoreFrameworkProjectSettings
  • Per-developer debug prefs from CoreFrameworkPreferences

These values are then consumed at runtime (e.g., by Bootstrapper).

Fields (defaults shown)

public static class CoreFrameworkSettings
{
    /// Name of the game start scene. "None" disables loading.
    public static string StartScene = "None";

    /// Name of the boot scene. "None" disables loading.
    public static string BootScene  = "None";

    /// Show debug messages controlled by CoreFramework utilities.
    public static bool ShowDebug;

    /// Rich-text font sizes for info/warn/error logs.
    public static int InfoSize    = 14;
    public static int WarningSize = 15;
    public static int ErrorSize   = 16;
}

In the Editor, these are set on load from the Preferences/Project Settings. In a built player, set them via your own bootstrap/config if needed.

Typical usage

Scene boot flow (used by Bootstrapper)

// Boot scene load (simplified)
if (!string.IsNullOrWhiteSpace(CoreFrameworkSettings.BootScene) &&
    !string.Equals(CoreFrameworkSettings.BootScene, "None", StringComparison.Ordinal))
{
    SceneManager.LoadScene(CoreFrameworkSettings.BootScene);
}

// Start scene load (built player path)
if (!string.IsNullOrWhiteSpace(CoreFrameworkSettings.StartScene) &&
    !string.Equals(CoreFrameworkSettings.StartScene, "None", StringComparison.Ordinal))
{
    SceneManager.LoadSceneAsync(CoreFrameworkSettings.StartScene, LoadSceneMode.Additive);
}

Consistent debug formatting (pair with your own base class)

using UnityEngine;

public abstract class CoreFrameworkDebugBehaviour : MonoBehaviour
{
    protected void LogInfo(string message, Object ctx = null)
    {
        if (CoreFrameworkSettings.ShowDebug)
            Debug.Log($"<size={CoreFrameworkSettings.InfoSize}><color=blue>Info:</color> {message}</size>", ctx);
    }

    protected void LogWarning(string message, Object ctx = null)
    {
        if (CoreFrameworkSettings.ShowDebug)
            Debug.LogWarning($"<size={CoreFrameworkSettings.WarningSize}><color=orange>Warning:</color> {message}</size>", ctx);
    }

    protected void LogError(string message, Object ctx = null)
    {
        Debug.LogError($"<size={CoreFrameworkSettings.ErrorSize}><color=red>Error:</color> {message}</size>", ctx);
    }
}

Notes

  • Editor population: Happens via [InitializeOnLoad] in CoreFrameworkSettingInitialization.

  • Build settings: Scene names must be listed in File → Build Settings… to load by name.

  • Team vs. personal:

    • StartScene/BootScene come from Project Settings (team-shared).
    • ShowDebug/sizes come from Preferences (per-developer).
