Unity 6 Core Framework

CoreFramework — Documentation Pack

This pack gives you a complete, production‑ready setup for API Reference (auto‑generated from your C# XML comments) and a Manual/Guide, built with DocFX and deployed to GitHub Pages from the gh-pages branch.

Targets your repository layout: Runtime/, Editor/, Tests/. It assumes code lives on main and the website publishes from gh-pages.

Quick Start (TL;DR)

  1. Copy this whole pack into the repo root.
  2. Commit.
  3. (Optional, first time only) In GitHub → Settings → Pages: set Source to Deploy from a branch, Branch: gh-pages / root.
  4. Push to main. GitHub Actions builds and publishes docs to gh-pages automatically.

Local build test:

# Windows (build only)
choco install docfx -y
# OR use dotnet tool if you already have docfx v3 preview installed; this pack expects DocFX v2
# dotnet tool install -g docfx # (v3 preview – not recommended here)

# 1) Generate metadata first (once per change to code)
docfx metadata

# 2) Generate grouped TOC
./tools/Generate-ApiToc.ps1

# 3) Build site (toc.yml will be honored for left nav)
docfx build --serve

      - name: Add .nojekyll

      # ⬇️ Upload the built site as an artifact (optional but handy)

          name: site

# Unity 6 Core Framework

A modular Unity 6 framework providing:
- **Extensions** (AsyncOperation, Camera, Color, Enumerable/Enumerator, GameObject, LayerMask, List, Number, PropertyPath, Reflection, Rigidbody, String, Task, Transform, Vector2/3)
- **Mathematics** utilities (`ulong2`, `ulong4`, and related `math` partials)
- **Patterns** (Factory/IGameAssetFactory, SharedData, Visitor)
- **Random** (noise‑based RNGs: SquirrelNoise 32/64/128, CryptoNoise, helpers, and docs)
- **Settings** (CoreFrameworkSettings, VersionControl)
- **Editor** (Preferences & Project Settings providers, tools, build processing)
- **Bootstrapper** (startup flow)

- **Manual** → [Start here](manual/getting-started.md)
- **API Reference** → [Browse namespaces](api/index.md)

# Getting Started

## Install via UPM
Add this Git URL in **Unity Package Manager** → **Add package from git URL**:

https://github.com/JamesLaFritz/Unity6CoreFramework.git


## Package Layout

manual/faq.md

# FAQ

**Why don’t Unity/Editor types resolve in API pages?**  
DocFX only includes your namespaces. External Unity types are referenced but not documented here.

**Where do the RNG design markdowns show up?**  
They’re added from `Runtime/Random/docs/**.md` into the site build and linked from *Random (Noise & Crypto)*.

Skinning the API pages so they read more like Unity’s docs (Classes / Structs / Interfaces / Enums … under each namespace).

DocFX can be skinned and the API pages reshaped so they read more like Unity’s docs (Classes / Structs / Interfaces / Enums … under each namespace).

templates/unity/partials/ManagedReference.namespace.tmpl.partial

{%- comment -%}
Groups types in a namespace like Unity docs (Classes/Structs/Interfaces/Enums/Delegates).
Drop-in override for DocFX v2 "default" template.
{%- endcomment -%}

<div class="unity-namespace">
  <h1 class="page-title">{{ model.name }}</h1>
  <p class="lead">{{ model.summary | strip_html }}</p>

  {%- assign all = model.members | default: model.items -%}
  {%- assign classes     = all | where_exp: "t", "t.type | downcase == 'class'"      | sort: "name" -%}
  {%- assign interfaces  = all | where_exp: "t", "t.type | downcase == 'interface'"  | sort: "name" -%}
  {%- assign structs     = all | where_exp: "t", "t.type | downcase == 'struct'"     | sort: "name" -%}
  {%- assign enums       = all | where_exp: "t", "t.type | downcase == 'enum'"       | sort: "name" -%}
  {%- assign delegates   = all | where_exp: "t", "t.type | downcase == 'delegate'"   | sort: "name" -%}

  {%- assign groups = 
    "Classes,classes;Structs,structs;Interfaces,interfaces;Enumerations,enums;Delegates,delegates" 
    | split: ";" -%}

  {%- for g in groups -%}
    {%- assign pair = g | split: "," -%}
    {%- assign title = pair[0] -%}
    {%- assign key = pair[1] -%}
    {%- assign list = nil -%}
    {%- case key -%}
      {%- when "classes"    -%}{%- assign list = classes    -%}
      {%- when "structs"    -%}{%- assign list = structs     -%}
      {%- when "interfaces" -%}{%- assign list = interfaces  -%}
      {%- when "enums"      -%}{%- assign list = enums       -%}
      {%- when "delegates"  -%}{%- assign list = delegates   -%}
    {%- endcase -%}

    {%- if list and list.size > 0 -%}
	  <!-- NOTE: key gives us unity-group--classes/structs/interfaces/enums/delegates -->
      <section class="unity-group unity-group--{{ key }}">
        <h2>{{ title }}</h2>
        <ul class="unity-list">
        {%- for t in list -%}
          <li class="kind-{{ t.type | downcase }}">
            <a href="{{ t.href }}">{{ t.name }}</a>
            {%- if t.summary %} — <span class="summary">{{ t.summary | strip_html }}</span>{% endif -%}
          </li>
        {%- endfor -%}
        </ul>
      </section>
    {%- endif -%}
  {%- endfor -%}
</div>

Tools/Generate-ApiToc.ps1

<#  Generate-ApiToc.ps1 v3.1  (PowerShell 5.1 compatible)
    - Default: namespaces-only TOC (Unity-style: CoreFramework → Mathematics/Random/Settings/Tools/…)
    - -IncludeTypes: also list types under each namespace (grouped)
    - -IncludeNestedTypes: include nested types like Foo.Bar
	
	.\tools\Generate-ApiToc.ps1 -IncludeTypes:$false -IncludeNestedTypes:$false
#>

[CmdletBinding()]
param(
  [string]$DocRoot,
  [string]$ApiDir = 'api',
  [string]$OutFile = 'api/toc.yml',
  [string]$RootNamespace = 'CoreFramework',
  [switch]$IncludeTypes,
  [switch]$IncludeNestedTypes
)

# Default switches to ON unless caller explicitly provides $false
if (-not $PSBoundParameters.ContainsKey('IncludeTypes'))        { $IncludeTypes = $true }
if (-not $PSBoundParameters.ContainsKey('IncludeNestedTypes'))  { $IncludeNestedTypes = $true }

function Resolve-DocRoot {
  param([string]$Hint)
  if ($Hint -and (Test-Path (Join-Path $Hint 'docfx.json'))) { return (Resolve-Path $Hint).Path }
  $dir = Get-Item $PSScriptRoot
  while ($dir) {
    if ((Test-Path (Join-Path $dir.FullName 'docfx.json')) -and (Test-Path (Join-Path $dir.FullName $ApiDir))) {
      return $dir.FullName
    }
    $dir = $dir.Parent
  }
  throw "Could not find docfx.json and '$ApiDir/' by walking up from $PSScriptRoot. Pass -DocRoot."
}

$DocRoot = Resolve-DocRoot -Hint $DocRoot
$ApiPath = Join-Path $DocRoot $ApiDir
$OutPath = Join-Path $DocRoot $OutFile

if (!(Test-Path $ApiPath)) { throw "API directory not found: $ApiPath. Run 'docfx metadata' first." }

$HasYaml = Get-Command ConvertFrom-Yaml -ErrorAction SilentlyContinue

function Read-YamlItem {
  param([string]$File)
  $raw = Get-Content -Raw $File
  if ($HasYaml) {
    try {
      $y = ConvertFrom-Yaml -Yaml $raw
      return $y.items[0]
    } catch {
      # fall through to lightweight parser
    }
  }
  # Minimal top-level field grabber
  $lines = $raw -split "`r?`n"
  $uid=$null; $type=$null; $name=$null; $ns=$null
  foreach ($ln in $lines) {
    if (-not $uid  -and $ln -match '^\s*-?\s*uid:\s*(.+)$') { $uid  = $Matches[1].Trim(); continue }
    if (-not $type -and $ln -match '^\s*type:\s*(.+)$')     { $type = $Matches[1].Trim(); continue }
    if (-not $name -and $ln -match '^\s*name:\s*(.+)$')     { $name = $Matches[1].Trim(); continue }
    if (-not $ns   -and $ln -match '^\s*namespace:\s*(.+)$'){ $ns   = $Matches[1].Trim(); continue }
    if ($uid -and $type -and $name) { break }
  }
  return [pscustomobject]@{ uid=$uid; type=$type; name=$name; namespace=$ns }
}

# --- collect namespaces & types ---
$files = Get-ChildItem $ApiPath -Filter *.yml -File | Where-Object { $_.Name -ne 'toc.yml' }

# Collect all items first (2-pass)
$allItems = @()
foreach ($f in $files) {
  $it = Read-YamlItem $f.FullName
  if ($it) {
    $it | Add-Member -NotePropertyName href -NotePropertyValue $f.Name
    $allItems += $it
  }
}

# Sets we’ll use
$realNs   = New-Object 'System.Collections.Generic.HashSet[string]' # only items with type == Namespace
$typeUids = New-Object 'System.Collections.Generic.HashSet[string]' # every non-namespace uid

foreach ($it in $allItems) {
  $kind = (($it.type) | Out-String).Trim()
  if ($kind -eq 'Namespace') {
    $null = $realNs.Add($it.uid)
  } else {
    $null = $typeUids.Add($it.uid)
  }
}

$nsMap = @{} # nsId -> object with name, href, children:Set[string], types:buckets

function New-NSNode([string]$nsId, [string]$href) {
  $last = ($nsId -split '\.')[-1]
  return @{
    name     = $last
    href     = $href
    children = ([System.Collections.Generic.HashSet[string]]::new())
    types    = @{
      class     = (New-Object System.Collections.ArrayList)
      struct    = (New-Object System.Collections.ArrayList)
      interface = (New-Object System.Collections.ArrayList)
      enum      = (New-Object System.Collections.ArrayList)
      delegate  = (New-Object System.Collections.ArrayList)
    }
  }
}

function Ensure-NS([string]$nsId, [string]$href) {
  if (-not $nsMap.ContainsKey($nsId)) { $nsMap[$nsId] = New-NSNode $nsId $href }
  elseif ($href -and -not $nsMap[$nsId].href) { $nsMap[$nsId].href = $href }
}

foreach ($item in $allItems) {
  $kind = (($item.type) | Out-String).Trim()
  $href = $item.href

  if ($kind -eq 'Namespace') {
    Ensure-NS $item.uid $href
    continue
  }

  # Determine logical namespace for the type
  $ns = $item.namespace
  if (-not $ns) {
    if ($item.uid -and ($item.uid -match '^(.*)\.[^.]+$')) { $ns = $Matches[1] } else { continue }
  }

  # Flatten nested-type "namespaces" (e.g., CoreFramework.Mathematics.ulong2)
  # If the last segment is actually a type full UID, drop that segment.
  $lastDot = $ns.LastIndexOf('.')
  if ($lastDot -gt 0) {
    $maybeType = $ns.Substring($lastDot + 1)
    $outerNs   = $ns.Substring(0, $lastDot)
    if ($typeUids.Contains("$outerNs.$maybeType")) {
      $ns = $outerNs
    }
  }

  Ensure-NS $ns $null

  if ($IncludeTypes) {
    $bucket = switch ($kind.ToLowerInvariant()) {
      'class'     { 'class' }
      'struct'    { 'struct' }
      'interface' { 'interface' }
      'enum'      { 'enum' }
      'delegate'  { 'delegate' }
      default     { $null }
    }
    if ($bucket) {
      [void]$nsMap[$ns].types[$bucket].Add([ordered]@{ name=$item.name; href=$href })
    }
  }
}

# parent/child links
foreach ($nsId in $nsMap.Keys) {
  $lastDot = $nsId.LastIndexOf('.')
  if ($lastDot -gt 0) {
    $parent = $nsId.Substring(0, $lastDot)
    if ($nsMap.ContainsKey($parent)) { $null = $nsMap[$parent].children.Add($nsId) }
  }
}

# ensure hrefs for NS without explicit yml
foreach ($nsId in $nsMap.Keys) {
  if (-not $nsMap[$nsId].href) {
    $guess = ($nsId + '.yml')
    if (Test-Path (Join-Path $ApiPath $guess)) { $nsMap[$nsId].href = $guess }
    else { $nsMap[$nsId].href = $guess } # fallback; DocFX may warn if it truly doesn't exist
  }
}

function Get-DirectNamespaceChildren {
  param([string]$nsId)
  $prefix = "$nsId."
  return @(
    @($realNs) |
      Where-Object { $_.StartsWith($prefix) -and ($_.Substring($prefix.Length) -notmatch '\.') } |
      Sort-Object
  )
}

# --- write helpers ---
$sb = New-Object System.Text.StringBuilder
function Add-Line([string]$s){ [void]$sb.AppendLine($s) }

function Write-NS {
  param([string]$nsId, [int]$indent = 2)
  $pad = ' ' * $indent
  $node = $nsMap[$nsId]
  Add-Line "$pad- name: $($node.name)"
  Add-Line "$pad  href: $($node.href)"

  # --- only recurse into namespaces ---
  #$nsChildren = @($node.children | Where-Object { $_ -and $nsMap.ContainsKey($_) } | Sort-Object)
  $nsChildren = @(Get-DirectNamespaceChildren -nsId $nsId)

  $hasTypes = $false
  if ($IncludeTypes) {
    if ($node.types.class.Count -or $node.types.struct.Count -or
        $node.types.interface.Count -or $node.types.enum.Count -or
        $node.types.delegate.Count) { $hasTypes = $true }
  }

  if ($nsChildren.Count -gt 0 -or $hasTypes) { Add-Line "$pad  items:" }

  foreach ($child in $nsChildren) { Write-NS -nsId $child -indent ($indent + 4) }

  if ($IncludeTypes) {
    $groups = @(
      @{title='Classes';      key='class'    },
      @{title='Structs';      key='struct'   },
      @{title='Interfaces';   key='interface'},
      @{title='Enumerations'; key='enum'     },
      @{title='Delegates';    key='delegate' }
    )
    foreach ($g in $groups) {
      $arr = $node.types[$g.key]
      if ($arr.Count -gt 0) {
        Add-Line "$pad    - name: $($g.title)"
        Add-Line "$pad      items:"
        foreach ($t in ($arr | Sort-Object { $_.name })) {
          Add-Line "$pad        - name: $($t.name)"
          Add-Line "$pad          href: $($t.href)"
        }
      }
    }
  }
}

# roots
$roots = @()
if ($realNs.Contains($RootNamespace)) {
  $roots = @($RootNamespace)
} else {
  $roots = @(@($realNs) | Where-Object { $_ -notmatch '\.' } | Sort-Object)
}

Add-Line '### YamlMime:TableOfContent'
Add-Line 'items:'
foreach ($r in $roots) { Write-NS -nsId $r }

# write file
$null = New-Item -ItemType Directory -Force -Path $ApiPath | Out-Null
$sb.ToString() | Set-Content -Path $OutPath -Encoding UTF8
Write-Host "Wrote $OutPath"
